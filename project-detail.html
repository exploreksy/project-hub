배경 및 문제 정의

여러 프로젝트를 진행했지만 각기 다른 저장소와 포맷에 흩어져 있어, 채용 담당자에게 일관된 인상을 주기 어려웠습니다. "프로젝트 성격이 달라도 하나의 완성도 있는 포트폴리오처럼 보이게 하자"는 목표로 통일된 비주얼 언어를 가진 허브 페이지를 기획하게 되었습니다.

주요 기능

  • 인트로 페이지 — 밤하늘 파티클 애니메이션과 Enter 버튼으로 첫인상을 전달
  • 프로젝트 리스트 — 3열 카드 그리드, hover 시 퍼플 오버레이 인터랙션
  • 프로젝트 상세 — 배경/기능/트러블슈팅/회고를 세로 스크롤로 몰입감 있게 구성

기술 스택 & 아키텍처

별도 빌드 도구 없이 정적 HTML/CSS/JS로 구현했습니다. 파티클 배경은 Canvas API로 직접 그렸고, 스크린샷 섹션은 IntersectionObserver로 스크롤 진입 시 페이드인되도록 처리했습니다.

트러블슈팅

파티클 애니메이션이 텍스트 가독성을 해치는 문제
초기에는 파티클 밀도가 높고 밝기가 강해 타이틀 텍스트와 겹칠 때 가독성이 떨어졌습니다. 파티클 개수를 화면 면적 기준으로 줄이고, 투명도를 낮춰 은은한 느낌으로 조정해 해결했습니다.
인트로 페이지 전용 스타일이 다른 페이지에 영향을 준 문제
인트로 페이지의 overflow: hidden 설정이 스타일시트를 공유하는 리스트/상세 페이지에도 적용되어 스크롤이 막히는 문제가 있었습니다. 해당 스타일을 .intro-page 클래스로 분리해 인트로 페이지에만 적용되도록 수정했습니다.
